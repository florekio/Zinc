# v0.5.0

**Test262: 90.0% on a ~3x larger test scope** — 25,316 / 28,119 active tests pass. The conformance runner previously covered only the language suite (9,805 active tests, 95.7% in v0.4.0); it now runs the **language suite plus 32 built-ins suites** (`Array`, `Object`, `String`, `RegExp`, `Promise`, `Date`, `Function`, `Map`/`Set`, `Symbol`, typed arrays, …). The language suite alone stands at 96.4%. The in-repo test suite also grew from 94 to **238 tests** (94 VM unit tests, 111 end-to-end, plus parser and JIT suites).

## Highlights

### New capabilities

- **`AggregateError`** — full constructor with observable iterable-to-list (`@@iterator` protocol, poisoned getters propagate), observable `ToString(message)`, own `errors` property, subclassing; `Promise.any` rejects with real `AggregateError` instances
- **Promise combinator protocol** — `Promise.all`/`race`/`allSettled`/`any` run `GetIterator` on their argument (non-iterables and poisoned `@@iterator` reject the returned promise), invoke element `then` overrides observably, and settle through `NewPromiseCapability` for custom constructors
- **Class statics inherit from native built-ins** — `class P extends Promise` exposes `P.resolve`/`P.all`/… through the `__super__` chain on both property reads and method calls
- **Full `ArraySetLength`** — shrinking `length` deletes from the top down and stops at non-configurable indices; `defineProperty(arr, "length", {writable:false})` sticks; sparse arrays track large lengths via shadow properties without dense allocation
- **Real array holes** — elisions produce holes (not `undefined` elements), skipped by iteration, `in`, `hasOwnProperty`, and the array methods
- **Property descriptor machinery** — spec-shaped `ValidateAndApplyPropertyDescriptor`: getter-aware `ToPropertyDescriptor` in field order, non-configurable redefine rejection, accessor↔data conversions preserving creation order, `get`/`set: undefined` accessor halves
- **RegExp `@@replace` / `@@match` / `@@search` / `@@split`** — the full observable protocol (custom `exec`, `lastIndex` reads/writes, species constructors), early `SyntaxError` pattern validation, ES2025 modifier groups, `\p{…}` escapes; match results carry `.index` / `.input`
- **JSON rewritten** — `SerializeJSONProperty` per spec (`toJSON`, replacer, wrapper coercion, BigInt `TypeError`, indent support), live-path cycle detection, `JSON.parse` raises proper `SyntaxError`s
- **Date protocol** — `Date.parse` (ISO 8601 with offsets and extended years), spec `toString` family formats, component-overflow normalization in the setter families, extractable statics

### Correctness & hardening

- **Six native panics eliminated** — radix-1 `toString` infinite loop, `"x".repeat(Infinity)` capacity overflow, cyclic `JSON.stringify` stack overflow, `copyWithin` with end < start, `toExponential(Infinity)` formatter blowup, `padStart`/`padEnd` splitting multibyte fillers mid-char
- **Number formatter spec order** — `toFixed`/`toExponential`/`toPrecision` evaluate NaN/Infinity vs `RangeError` in the spec-mandated order, digits clamped to [0, 100]
- **Strict `ToPrimitive`** — objects without a usable `toString`/`valueOf` throw `TypeError`; own overrides on wrapper objects are honored
- **Built-in constructor `.prototype`** — a real own property: visible to `hasOwnProperty`, non-writable, non-deletable (strict mode throws)
- **`name`/`length` metadata everywhere** — every built-in prototype method and static reports spec values with correct descriptor attributes (writable false, enumerable false, configurable true)
- **`arr["length"] = n`** — computed-key writes route through `ArraySetLength` instead of minting an enumerable named property
- **Generic array-likes** — `Array.prototype` methods work spec-correctly on any object with `length` + index properties, with observable `ToNumber` coercion and hole semantics
- **Nested-call throw protection** — getters, `toJSON`, replacers, and comparators invoked from native code propagate exceptions without unwinding live frames

### Infrastructure

- **Test262 runner** — 32 built-ins categories added, category-parallel execution (4 workers, `ZINC_TEST262_JOBS` override), 20M-step budget + 10s wall-clock deadline per test, failure-log diffing workflow
- **End-to-end suite** — 111 e2e tests covering the interpreter pipeline against expected output
